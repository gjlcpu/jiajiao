# 高一数学互动学情报告：两份网页版源代码

## 目录
- report_25：25题互动学情报告
- report_18：18题互动学情报告

每个文件夹里有：
- `original.html`：原始单文件完整版本，CSS/JavaScript 已内嵌，双击可离线打开。
- `index.html`：分离 CSS 和 JavaScript 的可编辑版。
- `style.css`：网页的样式代码。
- `app.js`：参数滑块、图形变化及其他交互逻辑代码。

## 使用
1. 解压 ZIP。
2. 双击任意文件夹里的 `original.html`，即可像之前一样打开网页版。
3. 想修改代码，可以用 VS Code 打开对应文件夹，编辑 `index.html`、`style.css`、`app.js`；三个文件要放在同一个目录。
4. 原始单文件版在本地打开无需安装依赖或联网。

## 注意
网页中的题目与讲解沿用原版报告，未在此步骤重新核对数学内容。
